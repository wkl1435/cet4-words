# 四级词汇 · 49 天（离线版）

## 怎么打开
- 电脑双击 `启动服务器.bat`，浏览器会自动打开 http://127.0.0.1:8080/
- 手机连同一个 Wi-Fi，打开窗口里显示的 `http://192.168.x.x:8080/`
- 只想在电脑上看，直接双击 `index.html` 也行（手机不行）

## 功能
- 今日：按 49 天日程给出当天任务、倒计时、打卡
- 学习：卡片翻面，认识 / 模糊 / 不会，自动排 1/2/4/7/15 天复习
- 复习：到期词 + 错词本
- 测验：英译中四选一 / 中译英拼写 / 听写（听音拼写）
- 我的：导出 / 导入进度、生成 Markdown 报告、配套资料下载

## 注意
- 进度存在浏览器 localStorage，换浏览器或清缓存会丢，请定期“导出备份”
- 手机和电脑的进度各自独立，用导出 / 导入同步
